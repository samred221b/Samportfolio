# Samuel Alemayehu - Portfolio Website

A modern, elegant, and minimal portfolio website showcasing the professional experience and projects of Samuel Alemayehu, a Full-Stack Developer, Data Analyst, and IT Officer from Ethiopia.

## 🚀 Features

- **Modern Design**: Clean, professional layout with smooth animations
- **Responsive**: Fully responsive design that works on all devices
- **Interactive**: Engaging user interface with hover effects and transitions
- **Performance Optimized**: Fast loading and smooth scrolling experience
- **Accessible**: Built with accessibility best practices

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: CSS animations and transitions
- **Build Tool**: Create React App

## 📋 Sections

1. **Hero Section**: Professional introduction with call-to-action buttons
2. **Skills**: Technical skills with progress indicators and technology tags
3. **Experience**: Professional timeline with detailed role descriptions
4. **Projects**: Interactive project showcase with carousel and grid views
5. **Certifications**: Professional certifications and achievements
6. **Education**: Academic background and continuous learning
7. **Languages**: Language proficiency and communication skills
8. **Footer**: Contact information and social links

## 🎨 Design Features

- **Color Scheme**: Clean white background with royal blue and teal accents
- **Typography**: Inter and Poppins fonts for modern readability
- **Animations**: Subtle fade-ins, slide-ups, and hover effects
- **Layout**: Centered design with maximum width of 1200px
- **Shadows**: Soft shadows and glassmorphism effects

## 🚀 Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/samuelalemayehu/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### Building for Production

```bash
npm run build
```

This builds the app for production to the `build` folder.

## 🔧 Customization

### Colors
Update the color scheme in `tailwind.config.js`:
```javascript
colors: {
  primary: {
    // Your primary colors
  },
  accent: {
    // Your accent colors
  }
}
```

### Content
Update personal information in the respective component files:
- `Hero.js` - Personal introduction
- `Experience.js` - Professional experience
- `Projects.js` - Project details
- `Skills.js` - Technical skills
